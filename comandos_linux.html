Navegação e Terminal

1

Localização e Identificação

Antes de alterar qualquer coisa, saiba onde você está e quem você é no sistema[cite: 3, 5, 6].

# Onde estou agora? (Caminho completo)
pwd

# Quem está usando o terminal?
whoami

# Identidade detalhada (Usuário, ID e grupos pertencentes)
id

# Em qual máquina/servidor estou conectado?
hostname
2

Navegando entre Pastas

Use o cd (Change Directory) para se movimentar pela árvore de arquivos[cite: 3, 6].

# Entrar em uma pasta específica
cd /home/aluno

# Voltar um nível de pasta (diretório acima)
cd ..

# Voltar direto para a sua pasta pessoal (Home)
cd ~
3

Organização e Histórico

Comandos úteis para manter a tela limpa e auditar o que foi feito[cite: 3, 6].

# Limpa visualmente o terminal
clear

# Mostra todo o histórico de comandos digitados
history
Dica de Segurança: Limpar a tela com clear não remove as evidências. Tudo continua registrado no history[cite: 3, 6].

Manipulação de Arquivos e Pastas

1

Listagem e Criação

Observe o conteúdo antes de agir e crie estruturas organizadas[cite: 3, 6].

# Lista arquivos e diretórios do local atual
ls

# Lista com detalhes (dono, permissões, tamanho)
ls -l

# Cria uma nova pasta
mkdir relatorios

# Cria várias pastas em sequência de uma vez
mkdir -p empresa/financeiro/relatorios

# Cria um arquivo vazio (ou atualiza a data de modificação)
touch notas.txt
2

Leitura de Arquivos

Diferentes formas de visualizar o conteúdo de um arquivo de texto no terminal[cite: 3, 6].

# Mostra todo o arquivo de uma vez (ideal para arquivos curtos)
cat arquivo.txt

# Abre em modo de paginação (use as setas e aperte 'q' para sair)
less arquivo.txt

# Mostra apenas as 10 primeiras linhas
head arquivo.txt

# Mostra apenas as 10 últimas linhas (excelente para logs)
tail arquivo.txt
3

Redirecionamento de Saída

Em vez de mostrar o texto na tela, você pode enviá-lo diretamente para um arquivo[cite: 3, 6].

# O símbolo > SOBRESCREVE o arquivo (apaga o que tinha antes)
echo "Status OK" > log.txt

# O símbolo >> ADICIONA texto ao final do arquivo (mais seguro)
echo "Novo evento" >> log.txt

Gerenciamento de Usuários e Grupos

1

Contas de Usuário

Criação, definição de senhas e remoção de contas[cite: 2, 5].

# Cria usuário com assistente interativo (pede senha e dados)
sudo adduser aluno01

# Altera a senha de uma conta
sudo passwd aluno01

# Remove um usuário
sudo userdel aluno02

# Remove o usuário e deleta a sua pasta /home inteira
sudo userdel -r aluno02
Alternativa Segura: Em um ambiente real, muitas vezes é melhor apenas bloquear a conta com sudo passwd -l usuario ao invés de apagá-la[cite: 5].
2

Gerenciamento de Grupos

Organize usuários com permissões em comum em grupos[cite: 2, 5].

# Cria um novo grupo (ambos os comandos funcionam)
sudo addgroup professores
sudo groupadd alunos

# Verifica se o grupo foi criado
getent group professores

# Adiciona o usuário a um grupo SEM remover os grupos anteriores (-aG)
sudo usermod -aG professores professor01

# Verifica a quais grupos um usuário pertence
groups professor01

Permissões e Propriedade (chmod)

1

Entendendo o ls -l

As permissões são divididas em 3 blocos: Dono, Grupo e Outros[cite: 5].
As letras significam: r (ler), w (escrever/alterar) e x (executar/entrar)[cite: 5].

# Saída de exemplo: -rwxr-x---
# Dono: rwx (Lê, escreve, executa)
# Grupo: r-x (Lê, executa)
# Outros: --- (Nenhum acesso)
2

Alterando Permissões (Modo Simbólico e Numérico)

O chmod modifica quem pode acessar o arquivo. No formato numérico, some: 4 (r) + 2 (w) + 1 (x)[cite: 5].

# Modo Simbólico: u (user/dono), g (group), o (others/outros)
chmod u+x script.sh     # Dá execução para o dono
chmod g+w projeto.txt   # Dá escrita para o grupo
chmod o-r segredo.txt   # Remove leitura dos outros

# Modo Numérico (Dono=7, Grupo=5, Outros=0)
chmod 750 pasta_segura  # 7 (rwx) para dono, 5 (r-x) para grupo, 0 (---) p/ outros
chmod 640 relatorio     # 6 (rw-) para dono, 4 (r--) para grupo, 0 (---) p/ outros
3

Alterando Propriedade e ACLs

Mude o dono (chown), o grupo (chgrp) ou crie exceções específicas (setfacl)[cite: 5].

# Altera apenas o dono do arquivo
sudo chown professor aula.txt

# Altera apenas o grupo dono do arquivo
sudo chgrp professores aula.txt

# Altera ambos simultaneamente (dono:grupo)
sudo chown professor:professores aula.txt

# Concede leitura de um arquivo para um usuário específico (ACL)
setfacl -m u:aluno01:r relatorio.txt

Serviços, Daemons e systemd

1

Diagnóstico de Serviços

O systemctl conversa com o systemd para gerenciar os serviços[cite: 4]. E o ss mapeia as portas[cite: 1, 4].

# Mostra o estado atual de um serviço (se está rodando ou com erro)
systemctl status ssh
systemctl status apache2

# Lista portas abertas e serviços em escuta no servidor (TCP/UDP)
ss -tuln
2

Controle de Execução e Boot

Ligue, desligue e configure o serviço para iniciar com a máquina[cite: 1, 4].

# Inicia / Para / Reinicia o serviço AGORA
sudo systemctl start ssh
sudo systemctl stop ssh
sudo systemctl restart ssh

# Habilita o serviço para iniciar SOZINHO ao ligar o sistema (boot)
sudo systemctl enable ssh

# Desabilita a inicialização automática
sudo systemctl disable ssh

Configuração de Rede e IP Estático

1

Reconhecimento de Rede

Descubra os endereços IP atuais e identifique os nomes das suas placas de rede[cite: 7, 9].

# Mostra interfaces e endereços IPs atuais
ip a

# Mostra tabela de roteamento (útil para validar o gateway)
ip route

# Lista dispositivos gerenciados pelo Network Manager
nmcli device

# Mostra as conexões de rede configuradas
nmcli connection show
2

Configurando IP Manual (Estático)

Para desabilitar o DHCP e fixar um IP usando o nmcli, você precisa modificar 4 parâmetros[cite: 9].

# 1. Desabilita o DHCP e define configuração manual
sudo nmcli connection modify "Wired connection 1" ipv4.method manual

# 2. Define o endereço IP e a máscara (ex: /24)
sudo nmcli connection modify "Wired connection 1" ipv4.addresses 192.168.10.201/24

# 3. Define o Gateway da rede
sudo nmcli connection modify "Wired connection 1" ipv4.gateway 192.168.10.1

# 4. Define o Servidor DNS
sudo nmcli connection modify "Wired connection 1" ipv4.dns "192.168.10.1"
3

Aplicando a Nova Configuração

Após rodar o modify, é obrigatório "reiniciar" a conexão na interface para as regras entrarem em vigor[cite: 9].

# Desativa a conexão de rede atual
sudo nmcli connection down "Wired connection 1"

# Reativa a conexão aplicando o novo IP manual
sudo nmcli connection up "Wired connection 1"

SSH e Transferência de Arquivos

1

Conexão SSH Básica

O SSH permite o acesso seguro ao terminal de outra máquina. O daemon (`sshd`) atua escutando requisições, normalmente na porta 22[cite: 1, 46].

# Sintaxe: ssh [usuario]@[ip_do_servidor]
ssh aluno@192.168.1.100

# Para conectar especificando uma porta diferente da porta padrão 22:
ssh -p 2222 aluno@192.168.1.100
2

Transferência via SCP (Secure Copy)

O comando SCP copia arquivos entre computadores usando a mesma segurança e criptografia do SSH.

# Enviar arquivo LOCAL para o servidor REMOTO
scp arquivo.txt aluno@192.168.1.100:/home/aluno/

# Baixar arquivo do servidor REMOTO para a máquina LOCAL (o ponto final significa 'pasta atual')
scp aluno@192.168.1.100:/home/aluno/backup.zip .

# Enviar uma pasta inteira e seu conteúdo (-r de recursivo)
scp -r pasta_local/ aluno@192.168.1.100:/home/aluno/
3

Sessão Interativa com SFTP

O SFTP abre um prompt interativo seguro, semelhante ao FTP, ideal para navegar nas pastas remotas antes de transferir.

# Iniciar a conexão SFTP
sftp aluno@192.168.1.100

# Comandos usados DENTRO do prompt sftp> :
ls                 # Lista os arquivos remotos
put relatorio.pdf  # Faz o UPLOAD do arquivo para o servidor
get backup.tar.gz  # Faz o DOWNLOAD do arquivo do servidor para sua máquina
exit               # Encerra a sessão sftp

Samba e Mapeamento de Rede

1

Entendendo o arquivo smb.conf

O Samba permite compartilhar arquivos na rede utilizando a porta 445 (SMB)[cite: 1, 40]. A configuração base é feita no arquivo /etc/samba/smb.conf. Veja o que cada diretiva faz:

  • path: O caminho exato da pasta no servidor Linux (ex: /var/samba/publico).
  • browsable: Se definido como yes, a pasta aparecerá visível na lista de diretórios quando alguém acessar o IP do servidor. Se no, ela fica oculta (o usuário precisa digitar o caminho exato para acessá-la).
  • read only: Proteção de gravação. Se yes, os usuários só podem baixar/ler arquivos. Se no, eles podem criar e modificar arquivos (desde que o chmod do Linux também permita).
  • guest ok: Controle de acesso anônimo. Se yes, qualquer pessoa acessa a pasta sem precisar de usuário/senha. Se no, o acesso é bloqueado para visitantes.
  • valid users: Restringe o acesso de forma rígida. Você pode especificar usuários separados por vírgula (ex: aluno01, admin) ou bloquear por grupos usando o símbolo @ (ex: @professores).
# Edite o arquivo (exige sudo)
sudo nano /etc/samba/smb.conf

# Exemplo prático de uma configuração no final do arquivo:
[Publico]
   path = /var/samba/publico
   browsable = yes
   read only = no
   guest ok = no
   valid users = aluno01, @suporte
2

Gerenciamento de Senhas do Samba (smbpasswd)

O Samba não usa a senha principal do Linux para conexões de rede, ele possui um banco de senhas próprio. Você deve cadastrar o usuário explicitamente no Samba.

# O parâmetro -a (Add) vincula o usuário ao Samba e pede para definir a senha de rede
sudo smbpasswd -a aluno01

# O parâmetro -e (Enable) reativa um usuário que foi desabilitado previamente
sudo smbpasswd -e aluno01

# Após qualquer alteração no smb.conf ou nos usuários, reinicie o serviço
sudo systemctl restart smbd nmbd
3

Montar Compartilhamento (Mount CIFS)

Para mapear uma pasta da rede diretamente no seu sistema de arquivos local do Linux, usamos o comando mount com o protocolo cifs (formato moderno do SMB).

# 1. Crie uma pasta vazia localmente que servirá como ponto de montagem (âncora)
sudo mkdir -p /mnt/rede_samba

# 2. Monte o compartilhamento mapeando para a pasta local criada
# Sintaxe: mount -t cifs //IP_DO_SERVIDOR/NomeDaPasta /Ponto/De/Montagem -o username=Usuario
sudo mount -t cifs //192.168.1.100/Publico /mnt/rede_samba -o username=aluno01

# Após digitar a senha, você pode navegar pelos arquivos como se fossem locais:
ls -l /mnt/rede_samba

# 3. Para desconectar (desmontar) a unidade de rede
sudo umount /mnt/rede_samba
Dica de Instalação: Para que o comando mount consiga entender o protocolo cifs, é necessário que o pacote cifs-utils esteja instalado na máquina cliente (`sudo apt install cifs-utils`).
