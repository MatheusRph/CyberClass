Navegação e Arquivos

1

Descobrir localização e usuário

pwd mostra o caminho completo da pasta atual[cite: 3, 6]. whoami mostra o nome do usuário conectado[cite: 3, 6].

pwd
whoami
2

Listar arquivos

ls lista arquivos e diretórios do local atual[cite: 3, 6]. Você pode usar opções como -l para detalhes[cite: 3, 6].

ls
ls -l
3

Manipular pastas e arquivos

mkdir cria pastas[cite: 3, 6]. cp cria uma cópia de um arquivo[cite: 3, 6]. mv move ou renomeia um arquivo[cite: 3, 6].

mkdir nova_pasta
cp arquivo.txt copia.txt
mv arquivo.txt /destino/

Usuários e Grupos

1

Gerenciar Usuários

Para criar um usuário, utilize sudo adduser nome[cite: 2, 5]. Para excluir o usuário e sua pasta /home, utilize sudo userdel -r nome[cite: 2, 5].

sudo adduser aluno01
sudo userdel -r aluno01
2

Gerenciar Grupos

Crie grupos com sudo addgroup nome[cite: 2] ou sudo groupadd nome[cite: 5]. Para consultar os grupos, use getent group[cite: 2].

sudo addgroup suporte
getent group
3

Adicionar Usuário ao Grupo

Use sudo usermod -aG grupo usuario para adicionar o usuário a um grupo sem apagar as participações antigas[cite: 2, 5].

sudo usermod -aG suporte aluno01

Permissões e Propriedade

1

Alterar permissões: Letras (Simbólico)

O chmod aceita u (dono), g (grupo) e o (outros)[cite: 5]. Use + (adicionar) ou - (remover) seguidos de r (leitura), w (escrita) e x (execução)[cite: 5].

chmod u+x script.sh
chmod g+w relatorio.txt
chmod o-r segredo.txt
2

Alterar permissões: Números (Octal)

Some os valores: 4 (leitura), 2 (escrita), 1 (execução)[cite: 5]. Um total de 7 significa permissão total (rwx), 6 significa leitura e escrita (rw-)[cite: 5].

chmod 750 projeto
chmod 640 relatorio.txt
3

Alterar dono e grupo (chown e chgrp)

O chown altera o usuário dono do arquivo[cite: 5]. O chgrp altera o grupo dono do arquivo[cite: 5]. É possível alterar ambos de uma vez usando dono:grupo[cite: 5].

sudo chown professor aula.txt
sudo chgrp professores aula.txt
sudo chown professor:professores aula.txt

Serviços, Daemons e Systemctl

1

Verificar Status e Reiniciar

systemctl status ssh mostra o estado do serviço SSH[cite: 1, 4]. sudo systemctl restart ssh reinicia o serviço SSH[cite: 1, 4].

systemctl status ssh
sudo systemctl restart ssh
2

Parar e Iniciar Serviços

sudo systemctl start ssh inicia o serviço agora[cite: 1, 4]. sudo systemctl stop ssh interrompe temporariamente o serviço[cite: 1, 4].

sudo systemctl start ssh
sudo systemctl stop ssh
3

Habilitar no Boot e Portas em Escuta

sudo systemctl enable ssh inicia automaticamente ao ligar o sistema[cite: 1, 4]. ss -tuln lista as portas abertas e serviços de escuta (TCP/UDP)[cite: 1, 4].

sudo systemctl enable ssh
ss -tuln

Configuração de Rede e Interfaces

1

Identificar Interfaces e Conexões

Para visualizar suas interfaces, utilize o ip a[cite: 7, 9]. Para checar seus dispositivos gerenciados e conexões ativas com o Network Manager, utilize os comandos nmcli device e nmcli connection show[cite: 9].

ip a
nmcli device
nmcli connection show
2

Configurar IP Manual via nmcli

Para aplicar um IP estático, desative o DHCP passando ipv4.method manual[cite: 9]. Em seguida, defina o endereço de IP com a máscara de rede (ex: /24), o gateway e o servidor DNS[cite: 9]. (Substitua "Wired connection 1" pelo nome da sua interface)[cite: 9].

sudo nmcli connection modify "Wired connection 1" ipv4.method manual
sudo nmcli connection modify "Wired connection 1" ipv4.addresses 192.168.10.201/24
sudo nmcli connection modify "Wired connection 1" ipv4.gateway 192.168.10.1
sudo nmcli connection modify "Wired connection 1" ipv4.dns "192.168.10.1"
3

Aplicar Configurações e Validar Rota

Depois de alterar as configurações, você deve derrubar a conexão (down) e ativá-la novamente (up) para que as regras entrem em vigor[cite: 9]. Verifique se o roteamento está correto com ip route[cite: 9].

sudo nmcli connection down "Wired connection 1"
sudo nmcli connection up "Wired connection 1"
ip route
