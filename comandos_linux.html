Navegação e Terminal

1

Localização e Identificação

Antes de alterar qualquer coisa, saiba onde você está e quem você é no sistema[cite: 3, 5, 6].

# Onde estou agora? (Caminho completo)
pwd

# Quem está usando o terminal?
whoami

# Identidade detalhada (Usuário, ID e grupos pertencentes)
id

# Em qual máquina/servidor estou conectado?
hostname
2

Navegando entre Pastas

Use o cd (Change Directory) para se movimentar pela árvore de arquivos[cite: 3, 6].

# Entrar em uma pasta específica
cd /home/aluno

# Voltar um nível de pasta (diretório acima)
cd ..

# Voltar direto para a sua pasta pessoal (Home)
cd ~
3

Organização e Histórico

Comandos úteis para manter a tela limpa e auditar o que foi feito[cite: 3, 6].

# Limpa visualmente o terminal
clear

# Mostra todo o histórico de comandos digitados
history
Dica de Segurança: Limpar a tela com clear não remove as evidências. Tudo continua registrado no history[cite: 3, 6].

Manipulação de Arquivos e Pastas

1

Listagem e Criação

Observe o conteúdo antes de agir e crie estruturas organizadas[cite: 3, 6].

# Lista arquivos e diretórios do local atual
ls

# Lista com detalhes (dono, permissões, tamanho)
ls -l

# Cria uma nova pasta
mkdir relatorios

# Cria várias pastas em sequência de uma vez
mkdir -p empresa/financeiro/relatorios

# Cria um arquivo vazio (ou atualiza a data de modificação)
touch notas.txt
2

Leitura de Arquivos

Diferentes formas de visualizar o conteúdo de um arquivo de texto no terminal[cite: 3, 6].

# Mostra todo o arquivo de uma vez (ideal para arquivos curtos)
cat arquivo.txt

# Abre em modo de paginação (use as setas e aperte 'q' para sair)
less arquivo.txt

# Mostra apenas as 10 primeiras linhas
head arquivo.txt

# Mostra apenas as 10 últimas linhas (excelente para logs)
tail arquivo.txt
3

Redirecionamento de Saída

Em vez de mostrar o texto na tela, você pode enviá-lo diretamente para um arquivo[cite: 3, 6].

# O símbolo > SOBRESCREVE o arquivo (apaga o que tinha antes)
echo "Status OK" > log.txt

# O símbolo >> ADICIONA texto ao final do arquivo (mais seguro)
echo "Novo evento" >> log.txt

Gerenciamento de Usuários e Grupos

1

Contas de Usuário

Criação, definição de senhas e remoção de contas[cite: 2, 5].

# Cria usuário com assistente interativo (pede senha e dados)
sudo adduser aluno01

# Altera a senha de uma conta
sudo passwd aluno01

# Remove um usuário
sudo userdel aluno02

# Remove o usuário e deleta a sua pasta /home inteira
sudo userdel -r aluno02
Alternativa Segura: Em um ambiente real, muitas vezes é melhor apenas bloquear a conta com sudo passwd -l usuario ao invés de apagá-la[cite: 5].
2

Gerenciamento de Grupos

Organize usuários com permissões em comum em grupos[cite: 2, 5].

# Cria um novo grupo (ambos os comandos funcionam)
sudo addgroup professores
sudo groupadd alunos

# Verifica se o grupo foi criado
getent group professores

# Adiciona o usuário a um grupo SEM remover os grupos anteriores (-aG)
sudo usermod -aG professores professor01

# Verifica a quais grupos um usuário pertence
groups professor01

Permissões e Propriedade (chmod)

1

Entendendo o ls -l

As permissões são divididas em 3 blocos: Dono, Grupo e Outros[cite: 5].
As letras significam: r (ler), w (escrever/alterar) e x (executar/entrar)[cite: 5].

# Saída de exemplo: -rwxr-x---
# Dono: rwx (Lê, escreve, executa)
# Grupo: r-x (Lê, executa)
# Outros: --- (Nenhum acesso)
2

Alterando Permissões (Modo Simbólico e Numérico)

O chmod modifica quem pode acessar o arquivo. No formato numérico, some: 4 (r) + 2 (w) + 1 (x)[cite: 5].

# Modo Simbólico: u (user/dono), g (group), o (others/outros)
chmod u+x script.sh     # Dá execução para o dono
chmod g+w projeto.txt   # Dá escrita para o grupo
chmod o-r segredo.txt   # Remove leitura dos outros

# Modo Numérico (Dono=7, Grupo=5, Outros=0)
chmod 750 pasta_segura  # 7 (rwx) para dono, 5 (r-x) para grupo, 0 (---) p/ outros
chmod 640 relatorio     # 6 (rw-) para dono, 4 (r--) para grupo, 0 (---) p/ outros
3

Alterando Propriedade e ACLs

Mude o dono (chown), o grupo (chgrp) ou crie exceções específicas (setfacl)[cite: 5].

# Altera apenas o dono do arquivo
sudo chown professor aula.txt

# Altera apenas o grupo dono do arquivo
sudo chgrp professores aula.txt

# Altera ambos simultaneamente (dono:grupo)
sudo chown professor:professores aula.txt

# Concede leitura de um arquivo para um usuário específico (ACL)
setfacl -m u:aluno01:r relatorio.txt

Serviços, Daemons e systemd

1

Diagnóstico de Serviços

O systemctl conversa com o systemd para gerenciar os serviços[cite: 4]. E o ss mapeia as portas[cite: 1, 4].

# Mostra o estado atual de um serviço (se está rodando ou com erro)
systemctl status ssh
systemctl status apache2

# Lista portas abertas e serviços em escuta no servidor (TCP/UDP)
ss -tulnp
2

Controle de Execução e Boot

Ligue, desligue e configure o serviço para iniciar com a máquina[cite: 1, 4].

# Inicia / Para / Reinicia o serviço AGORA
sudo systemctl start ssh
sudo systemctl stop ssh
sudo systemctl restart ssh

# Habilita o serviço para iniciar SOZINHO ao ligar o sistema (boot)
sudo systemctl enable ssh

# Desabilita a inicialização automática
sudo systemctl disable ssh

Rede e Interfaces (nmcli Completo)

1

Mapeamento e Gerenciamento de Conexões

Comandos essenciais para listar, criar e apagar conexões de rede usando o nmcli[cite: 117].

# Mostra o nome das conexões atuais
nmcli connection show

# Conectar a placa de rede específica (ex: enp0s3)
sudo nmcli device connect enp0s3

# Criar uma NOVA conexão ethernet associada a uma interface
sudo nmcli connection add type ethernet ifname enp0s3 con-name Rede-nat

# Apagar uma conexão de rede existente
sudo nmcli connection delete "Wired connection 1"

# Trocar o nome de identificação da rede
sudo nmcli connection modify Rede-nat connection.id Rede-NAT
2

Configurando IP (Manual vs DHCP)

Como alternar entre pegar o IP automaticamente via DHCP ou fixar um IP manual[cite: 117].

# Configurar a placa de rede para usar DHCP (Automático)
sudo nmcli connection modify Rede-nat ipv4.method auto

# Configurar IP MANUAL e atribuir o endereço (Ex: 192.168.15.10/24)
sudo nmcli connection modify Rede-local ipv4.method manual
sudo nmcli connection modify Rede-local ipv4.addresses 192.168.15.10/24
3

Aplicando as Alterações

Sempre que modificar algo no nmcli, você deve "subir" a interface novamente[cite: 117].

# Subir (ativar) a placa de rede para as regras entrarem em vigor
sudo nmcli connection up Rede-Aula

SSH e Transferência de Arquivos

1

Instalação e Conexão SSH

O SSH permite o acesso seguro ao terminal de outra máquina. Instale o pacote openssh-server e conecte-se[cite: 118].

# Instalar o servidor SSH na máquina alvo
sudo apt update
sudo apt install openssh-server

# Verificar se a porta padrão (22) está em escuta
sudo ss -tulnp | grep :22

# Acessar a VM/Servidor remotamente
ssh usuario@192.168.10.10

# Parar o serviço SSH se necessário
sudo systemctl stop ssh
2

Transferência via SCP (Secure Copy)

O SCP permite enviar ou receber arquivos de um servidor utilizando a criptografia do SSH[cite: 118].

# Enviar arquivo LOCAL para o servidor REMOTO
scp arquivo.txt usuario@IP_DO_SERVIDOR:/home/usuario/

# Enviar uma pasta inteira e seu conteúdo (recursivo -r)
scp -r avaliacao aluno01@192.168.10.10:/home/aluno01/

# Baixar arquivo do servidor REMOTO para a máquina LOCAL (inverta a ordem. O '.' indica pasta atual)
scp aluno01@192.168.10.10:/home/aluno01/relatorio.txt .
3

Permissões e Execução de Scripts (Bash)

Após enviar um script bash para o servidor, você precisa dar permissão de execução (+x) antes de rodar[cite: 118].

# Dá permissão de execução ao script
chmod +x instalar_guest_additions.bash

# Executa o arquivo no diretório atual (./) como superusuário
sudo ./instalar_guest_additions.bash

# Reinicia a máquina após a instalação
sudo reboot

Samba, Permissões e Compartilhamentos

1

Instalação e Entendimento do Serviço

O Samba permite compartilhar arquivos entre Linux e Windows através da rede, utilizando o protocolo SMB (Server Message Block)[cite: 119]. O daemon responsável é o smbd e ele escuta nativamente na porta TCP 445 e nas portas NetBIOS 137, 138 e 139[cite: 121, 122].

# Instalar os pacotes necessários do Samba
sudo apt install samba

# Verificar se o serviço smbd está ativo e rodando
systemctl status smbd
2

A Dupla Camada de Permissão (Linux + Samba)

Atenção: O Samba não substitui as permissões do Linux. O acesso precisa ser autorizado NAS DUAS camadas (Samba + Sistema de Arquivos)[cite: 127, 131].

# 1. Criação do grupo no Linux
sudo groupadd funcionarios

# 2. Adiciona usuário existente ao grupo
sudo usermod -aG funcionarios maria

# 3. Cria a pasta e associa ao grupo
sudo mkdir -p /srv/funcionarios
sudo chgrp funcionarios /srv/funcionarios

# 4. Ajusta permissões do Linux (Dono: rwx, Grupo: rwx, Outros: ---)
sudo chmod 770 /srv/funcionarios
3

Edição do smb.conf e Parâmetros Explicados

As configurações da rede ficam em /etc/samba/smb.conf. É recomendado fazer um backup (.bkp) antes de editar[cite: 128]. Entenda cada linha:

  • [Funcionarios]: Nome que aparecerá para as máquinas na rede[cite: 129].
  • path: Caminho real da pasta física no sistema Linux[cite: 129].
  • browseable = yes: Permite que o compartilhamento fique visível (não oculto) aos clientes da rede[cite: 130].
  • read only = no: Permite gravação/alteração (escrita). Se fosse 'yes', seria apenas leitura[cite: 130].
  • valid users = @funcionarios: Restringe o acesso. O @ indica que apenas membros do GRUPO "funcionarios" podem acessar[cite: 130, 131].
# Criar backup antes de alterar
sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.bkp

# Editar o arquivo de configuração
sudo nano /etc/samba/smb.conf

# Exemplo prático a ser inserido no final do arquivo:
[Funcionarios]
   path = /srv/funcionarios
   browseable = yes
   read only = no
   valid users = @funcionarios
4

Validação e Senhas (Autenticação Samba)

O Samba possui um cadastro de senhas próprio, separado do `/etc/passwd`. Todo usuário Linux precisa ser cadastrado no Samba para acessar a rede[cite: 133].

# Analisa o arquivo smb.conf em busca de erros de digitação antes de reiniciar
testparm

# Reinicia o serviço para o Samba ler a nova configuração
sudo systemctl restart smbd

# Cadastra a usuária 'maria' no sistema de autenticação do Samba (pedirá a nova senha SMB)
sudo smbpasswd -a maria

# Lista (consulta) todos os usuários registrados no banco do Samba
sudo pdbedit -L
Acesso via Windows: Com tudo configurado, no Windows você acessa utilizando o IP do servidor Linux, digitando: \\192.168.1.10\Funcionarios[cite: 135]. A rede pedirá o usuário (ex: maria) e a senha SMB cadastrada[cite: 135].
